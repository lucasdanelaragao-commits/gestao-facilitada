# Gestão Facilitada

Sistema de gestão para MEIs e escritório contábil (painel do Cliente, painel do ADM e equipe).

Os dados ficam na nuvem (Supabase): você entra de qualquer computador ou celular.

## Primeiro acesso do ADM
1. Abra o site com `#admin` no final do endereço.
2. Use o e-mail do administrador e crie a sua senha pessoal (ela nunca fica no código).
3. Depois, entre normalmente, sem `#admin`.

## Clientes e equipe
O ADM cadastra o cliente (ou o usuário da equipe) com uma senha provisória. No primeiro acesso, a pessoa é obrigada a criar a própria senha.
